# pgext.cloud 重构设计方案

> 把 pgext 从 "CLI 生成 53 万行 Markdown → Hugo 静态渲染" 重构为
> **`pgext server`：连接 PostgreSQL、动态渲染的单二进制 Web 服务**，
> 承载一个以"扩展宇宙"为核心体验的现代站点。
>
> 状态：**讨论稿**（2026-07-02）——先想清楚，再动手。

## TL;DR

- **架构**：`pgext server` = Go SSR + `pgx/v5` + 三层缓存 + go:embed 单二进制；
  前端用 Tailwind + Alpine + 一块自研 Canvas 星图，不引入 Node 运行时（[02](02-architecture.md)）；
- **数据**：现有管线一行不改，网站是纯读者；新增三个加性对象：
  搜索物化视图、访问统计表（一石二鸟）、星图布局表（[03](03-data.md)）；
- **路由**：旧 URL 一个不死；详情页从 531 扩到 **universe 全量 1,633**；
  `/zh` 全镜像——顺手解锁**已入库但从未发布的 531 篇中文文档**（[04](04-pages.md)）；
- **视觉**："星图志"方向——靛蓝夜空 × 暖金星光；签名元素是首页那块
  **由真实数据构成、随搜索聚焦的活宇宙**（1,633 星 · 16 星座 · 依赖连线）（[05](05-design-language.md)）；
- **节奏**：P0 骨架 3 天 → P1 平价迁移 + 中文解锁 1–2 周切 DNS → P2 星图/统计/徽章
  → P3 语义搜索/MCP/对比页（[06](06-roadmap.md)）。
