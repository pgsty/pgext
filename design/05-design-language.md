# 05 · 设计语言 —— "星图志 / Celestial Atlas"

## 方向陈述（以及我们刻意不做什么）

**不做**科幻霓虹（纯黑底 + 荧光绿粒子雨），**不做**通用 SaaS 模板脸
（大数字 + 渐变光斑 + 三列卖点卡）。

方向：**古典星图 × 现代数据仪表**。参照物是 Uranographia 那一代铜版星图志——
深靛夜空、暖金星光、发丝级的经纬刻度线、小型大写的星座标注——
用现代数据可视化的精度重新演绎。理由：这个隐喻不是贴皮，
**首页的星空就是数据集本身**（1,633 颗星 = 1,633 个扩展），
"图鉴/志"的气质也贴合站点的目录本性。

审美冒险只押注一处：**靛蓝夜空上的暖金**（而非 dev-tool 惯用的冷蓝高亮），
金色只给"活的东西"——星光、星座连线、焦点态、搜索命中。其余一切克制。

## 字体

| 角色 | 字体 | 说明 |
|---|---|---|
| Display（大标题） | **Bricolage Grotesque** | 有性格的怪诞体，只用于 ≥32px；避开 Inter/Space Grotesk 的默认脸 |
| 正文 | **IBM Plex Sans** | 仪器感、四平八稳；与 Mono 同族成套 |
| 中文 | **Noto Sans SC**（fallback PingFang SC） | 与 Plex 的灰度匹配良好 |
| 数据/代码 | **IBM Plex Mono** | 包名、版本号、矩阵、安装命令——本站一半内容是数据 |
| Atlas 标签 | Plex Sans **小型大写 + 0.12em 字距** | 星座名、区块 eyebrow、侧栏标题；配 Solar 色 60% ——古典星图的标注语法 |

规则：**凡是可复制的事实（包名/版本/命令/路径）一律 Mono**。
读者扫一眼就知道哪些字是"数据"，哪些字是"话"。

## 签名元素：活的宇宙（全站唯一的炫技点）

首页 hero = 一块全屏 Canvas，画的是**真实数据**，不是装饰粒子：

- **1,633 颗星**：位置来自 `pgext.layout`（固定种子力导向，按分类聚簇）——
  宇宙是**稳定**的，星星不会每天乱跳；新收录的扩展"诞生"在所属星座边缘；
- **星等 = log(stars)**，星色 = 分类色，微弱的闪烁频率 = 最近活跃度；
- **星座连线 = 真实的 `requires` 依赖边**（Solar 金、10% 透明度）：
  postgis 与它的 10 个依赖者连成的就是真实的"GIS 座"——这是数据集自己长出来的图案；
- **搜索即聚焦**：在中央搜索框每敲一个字，不匹配的星暗到 15%，匹配的星增辉并轻微放大
  ——输入 "vector"，整个宇宙收缩成 20 颗发亮的星。搜索框与可视化是同一个器官；
- **悬停**出星卡（名称/描述/分类/★），**点击**入详情页；
  底部 16 个星座图例 chip，点击平移聚焦该星座；
- `/galaxy` 是同一模块的全屏放大版（自由缩放、显示星座标签与全部连线）。

**工程边界**：Canvas 2D 手写约 500 行，零依赖；1,633 个点 60fps 毫无压力；
空间网格做 hover 拾取。现有 `static/galaxy` SPA 需要一次性拉 ~3.2MB 的全量 JSON；
新方案坐标由 `layout` 表预计算，首屏数据 ~100KB——30 倍的瘦身，也是"动态化"红利的直观例证。**降级**：无 JS / 爬虫 / 弱设备 → 服务端用同一份
`layout` 坐标渲染静态 SVG，视觉一致，语义上是一张 `<img>` + 完整 HTML 搜索表单。
移动端默认静态 + 搜索置顶。

## 动效纪律

- 首页加载编排（唯一的一段"演出"，共 ~1.2s）：星辰按星等分批淡入 →
  星座线描画 → 搜索框升起。`prefers-reduced-motion` → 全部跳过，直出终态；
- 内容页**零入场动画**；只保留 hover/focus 微反馈（120ms）与数字滚动（统计带，仅首页）；
- 矩阵格 hover：放大 1px 边框 + tooltip，无弹跳。

## 可达性与质量底线（不另行宣传，直接做到）

- 对比度 AA（Solar 在 Void 上 7.2:1，正文 12:1+）；
- 全键盘可达，focus ring = 2px Solar；
- 星图信息**永远**有 HTML 等价物（星空只是索引页的另一种投影，不是唯一入口）；
- 响应式到 360px；表格在窄屏降为卡片列表；
- 代码块/矩阵支持横向滚动，不撑破版心。
