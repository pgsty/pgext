# PGEXT 1.7.3

Prepared for release on 2026-11-23.

PGEXT 1.7.3 fixes build planning for extensions with no eligible PostgreSQL
major, tightens LLVM bitcode checks for extension packages, and adds four
source-only extensions to the catalog.

## Build fixes

- `pgext mak` and `pgext pkg` can now read a catalog containing an explicit
  empty `pg_ver` array (`{}`). When a major-specific recipe leaves its targets
  unspecified, this value rules out every major, even one requested with `--pg`.
  A blank field still allows platform defaults. Targets declared by the recipe
  take precedence.
- RPM and DEB verification now checks the package's internal name for a
  standalone extension `-llvmjit` package, including its debug companions.
  For an LLVM-enabled RPM recipe, verification requires both a bitcode module
  and its index in the main package under the selected PostgreSQL major.

## Catalog and guides

The Universe grows from 2,814 to **2,818 extensions**, with **627 packaged
entries**. Each addition has an English and a Chinese usage guide.

| New extension | What it provides |
| --- | --- |
| `int128` | Signed 128-bit integers with checked arithmetic and index support |
| `pg_iot` | Insert-only enforcement for registered tables |
| `pg_wget` | HTTP and HTTPS text downloads through the server's `wget` executable |
| `quick_sync` | Management of `postgres_fdw` connections and user mappings |

Seven existing guides were updated in both languages, including the PostgreSQL
19 planner hook and SQL upgrade for `pg_regresql` 2.2.1, Lua and C# support in
`plx` 3.1.0, and the repeated-character-class fix in `pg_tre` 4.6.6.

## Package availability

- PG19 is listed in the source compatibility range of **515** packaged catalog
  entries, up from 455. Of the 627 entries, **449** list PG19 on the RPM side
  and **441** on the DEB side. Individual operating systems and architectures
  have different coverage.
- The catalog updates 17 extension versions and records pgrx 0.20.1 as the
  build dependency for 63 packaged Rust extensions. RPM and DEB versions
  track the packages available from each supplier.
- The refreshed matrix covers **457 package families** across 16 Linux targets
  and PostgreSQL 15–19. Of 36,560 slots, **31,969** are available, **1,044**
  are missing, and **3,547** are not applicable.
