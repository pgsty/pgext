# PGEXT 1.7.2

Prepared for release on 2026-11-21.

PGEXT 1.7.2 adds PostgreSQL 19 to active build and availability targets,
retires PostgreSQL 14 from those targets, and refreshes the extension catalog
and bilingual usage documentation. PostgreSQL 18 remains the default for
generated configurations and build-tool installation.

## Build and repository targets

- Use PostgreSQL 15–19 across 16 Linux OS/architecture combinations. EL8
  continues to support PG15–18; its PG19 matrix cells are `N/A`.
- Select stable PGDG 19 repositories on EL9/EL10 and retire PG14 RPM and
  PG19 beta definitions from generated repository configurations.
- Reject explicit retired build targets and keep PG14-only recipes from
  falling back to unrelated catalog targets. Recipe support and installed
  development files still constrain each build.
- Filter fetch, scan, parse, configuration and live matrix queries to active
  dimensions while retaining historical catalog records.
- Add a transactional, idempotent build-target migration for existing
  databases. Follow the backup and preflight instructions in
  [the build workflow](https://github.com/pgsty/pgext/blob/v1.7.2/docs/build-workflow.md); do not replace dimension tables
  with `pgext load` to perform this transition.

## Catalog and documentation

- Include 2,814 Universe entries and 627 packaged catalog entries, including
  PostgreSQL 19's `pg_plan_advice` and `pg_stash_advice` modules.
- Refresh upstream releases, verified PG19 build capabilities and source
  metadata. Preserve the curated suppliers for AGE, Citus and `login_hook`.
  Build capability does not imply published binaries at every coordinate.
- Refresh bilingual usage documentation and add guides for newly catalogued
  extensions. Document version-specific configuration, privileges, upgrade
  paths and compatibility limits.
- Synchronize extension detail pages, indexes and matrix assets with the
  reviewed catalog and source stubs. Derive homepage PostgreSQL filters and
  matrix sizing from active dimensions.
- Update Pig CLI documentation and infrastructure release records. The
  Rust/pgrx package-toolchain document is a design proposal; this release does
  not switch the existing rustup/cargo-install implementation.

## Validation and compatibility

Release preparation checks include Go unit and disposable-database integration
tests, frontend tests, Python metadata/loader/changelog tests, full bilingual
stub Markdown lint, and the Hugo site build. The local authoritative catalog
CSV files and all 2,814 bilingual document rows match their source files.

The build baseline is Go 1.27.4, Hugo Extended 0.169.0 and OINK 1.5.1. The
accepted upstream LibSass deprecation warning remains visible.

Release artifacts retain the existing formats: Linux/macOS amd64/arm64
archives, Linux RPM/DEB packages, and SHA-256 checksums.
