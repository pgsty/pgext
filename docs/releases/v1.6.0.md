# PGEXT 1.6.0

Released on 2026-11-09.

PGEXT 1.6.0 improves the live catalog and native-build guidance, fixes legacy
RPM repository detection, and refreshes extension metadata and bilingual usage
guides. It follows the native build and repository-management commands introduced
in 1.5.0.

## Web application

- Derive homepage and About-page totals from the active catalog snapshot,
  including Universe entries, packaged entries, package families, and target slots.
- Refresh extension details and package matrices when catalog data changes,
  including updates that retain the same matrix timestamp and row count.
- Show native PGEXT build instructions according to recipe availability,
  independently of whether binary packages have been published.
- Preserve server-side package version ordering and improve responsive navigation.

## Native builds and configuration

- Recognize legacy Pigsty RPM repository key paths during repository migration.
- Add OpenBao and KES to generated infrastructure package selections.
- Update the CLI, API, and builder documentation for the current native workflow.

## Catalog and documentation

- Refresh the 2,733-entry Universe and 625-entry packaged baseline, including
  repository activity, source links, package versions, and build capabilities.
- Update package metadata for `pg_search` 0.26.6, `pg_improv` 0.14.0,
  `pg_tokenizer` and `vchord_bm25` 1.1.0, and `login_hook` 1.9.
- Keep Pigsty as the principal supplier for `login_hook`; retain the curated
  supplier choices for AGE and the Citus family.
- Refresh bilingual usage guides, extension pages, and the PGDG availability matrix.
- Reject mismatched English/Chinese package release histories before overwriting
  the changelog CSV. Add regression coverage and a CI regeneration check.

## Downloads and compatibility

Downloads include Linux and macOS archives for amd64 and arm64, Linux RPM/DEB
packages for both architectures, and SHA-256 checksums in `checksums.txt`.

The build baseline remains Go 1.27.3, Hugo Extended 0.168.0, and OINK 1.5.1.
The 1.5.0 command migration still applies: `pgext pkg` builds packages,
`pgext matrix` queries availability, and `pgext repo summary` queries repository
metadata. See the [build workflow](https://github.com/pgsty/pgext/blob/v1.6.0/docs/build-workflow.md)
and [server reference](https://github.com/pgsty/pgext/blob/v1.6.0/server/README.md).
