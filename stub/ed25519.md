`ed25519` — PostgreSQL extension for a modern and secure digital signature algorithm based on performance-optimized elliptic curves. Use it when implementing the corresponding security, audit, or access-control workflow. Use the pinned upstream revision linked above as the API boundary and test it on the target PostgreSQL build.

### Core Workflow

```sql
CREATE EXTENSION ed25519;
```

Install the extension in the intended database, run the smallest upstream example above when available, and verify the installed version and returned values before integrating it into application SQL.

### Important Objects

- `ed25519_create_keypair()` is an extension function and returns `TABLE`.
- `ed25519_sign(message bytea, signing_key bytea)` is an extension function and returns `bytea`.
- `ed25519_sign(message text, signing_key bytea)` is an extension function and returns `bytea`.
- `ed25519_verify(message bytea, verification_key bytea, signature bytea)` is an extension function and returns `boolean`.
- `ed25519_verify(message text, verification_key bytea, signature bytea)` is an extension function and returns `boolean`.

### Requirements and Caveats

- The reviewed control file declares default version `1.0`.
- The control file marks the extension as relocatable.
- Confirm privileges, supported PostgreSQL versions, upgrade behavior, and failure cases against the pinned source before production use.
